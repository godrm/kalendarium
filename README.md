# Kalendarium

> 하루 한 문장, 365일 라틴어 입문 — 대성당 도서관의 수도사와 함께

*Kalendarium*은 중세 기도서 맨 앞에 붙던 1년치 달력입니다. 날마다 한 줄씩 기념일이 적혀 있던 그 달력처럼, 이 프로젝트는 라틴어를 처음 배우는 사람이 **하루에 아주 쉬운 표현 하나씩, 1년 동안** 익숙해지도록 돕습니다.

## 기획 의도

- 라틴어는 문법이 어렵다는 인상 때문에 시작하기 부담스럽습니다. 문법보다 **짧은 표현에 매일 조금씩 익숙해지는 경험**을 먼저 주고 싶었습니다.
- 듀오링고처럼 몇 분이면 끝나는 짧은 레슨으로 매일 돌아오는 습관을 만듭니다.
- 중세 대성당 도서관에서 친절한 수도사가 한 구절씩 읽어 주는 분위기로, 공부라기보다 게임 속 NPC와 대화하는 느낌을 목표로 했습니다.

## 365개의 표현

인사말에서 시작해 짧은 문장, 유명한 격언 순서로 조금씩 어려워지도록 12개 단원으로 구성했습니다.

| 단원 | 주제 | 예시 |
|---|---|---|
| 1 | 인사와 기본 표현 | *Salve!* 안녕! |
| 2 | 나와 너 | *Nomen mihi est Marcus.* 내 이름은 마르쿠스야. |
| 3 | 가족과 사람 | *Amici sumus.* 우리는 친구야. |
| 4 | 숫자와 시간 | *Carpe diem.* 오늘을 붙잡아라. |
| 5 | 일상 동사 | *Lego librum.* 나는 책을 읽는다. |
| 6 | 자연과 날씨 | *Sol lucet.* 해가 빛난다. |
| 7 | 감정과 상태 | *Omnia vincit amor.* 사랑은 모든 것을 이긴다. |
| 8 | 음식·집·장소 | *Omnes viae Romam ducunt.* 모든 길은 로마로 통한다. |
| 9 | 학교와 배움 | *Docendo discimus.* 가르치면서 배운다. |
| 10 | 명령·부탁·질문 | *Cave canem!* 개 조심! |
| 11 | 유명한 격언 I | *Veni, vidi, vici.* 왔노라, 보았노라, 이겼노라. |
| 12 | 격언과 생활 속 라틴어 | *Et cetera, Status quo, Alter ego* |

일부 표현에는 어원, 문법, 역사 배경을 담은 짧은 메모가 붙어 있습니다.

## 하루의 레슨

1. **소개** — 수도사가 오늘의 표현과 뜻을 읽어 줍니다. 발음 듣기도 할 수 있습니다.
2. **뜻 고르기** — 라틴어를 보고 알맞은 한국어 뜻을 고릅니다.
3. **라틴어 고르기** — 한국어 뜻을 보고 알맞은 라틴어를 고릅니다.
4. **문장 완성** — 단어 조각을 순서대로 놓거나, 한 단어 표현은 직접 써 봅니다.
5. **마무리** — 틀린 문제는 한 번 더 풀고, 끝나면 어제와 그제 표현을 함께 복습합니다.

## 학습 규칙

- **처음 페이지를 연 날이 1일차**이고, 그날부터 하루에 한 표현씩 열립니다.
- 오늘의 표현과 함께 **어제·그제 표현까지** 다시 볼 수 있습니다. 내일 표현은 잠겨 있습니다.
- **연속 학습 일수**, **학습 N일째**, **실제로 공부한 날 수**를 기록해 보여 줍니다. 기록은 사용하는 브라우저에만 저장됩니다.
- 365일을 다 마치면 처음부터 2회차가 이어집니다.

## 안내자: 프라테르 안셀무스

대성당 도서관을 지키는 중년의 수도사 **Frater Anselmus**가 화면 아래 대화창에서 레슨을 이끕니다.

- 대사가 한 글자씩 나오는 게임식 대화창이고, 퀴즈 보기는 대화 선택지로 고릅니다.
- 상황에 따라 표정과 자세가 바뀝니다: 기본 안내, 정답(크게 웃음), 오답(다독임), 자료를 찾는 중(책 읽기), 레슨 완료(축하).

## 익숙한 언어로 연결 (선택 기능)

LLM API 키를 설정하면 오늘의 표현을 이미 아는 언어와 이어 볼 수 있습니다.

- 영어로는 어떻게 말하는지
- 스페인어·프랑스어·이탈리아어 등 다른 언어의 비슷한 표현
- 비슷한 한국어 표현이나 속담
- 같은 라틴어 뿌리에서 나온 단어 (예: *amo* → amateur)
- 외우기 쉬운 한 줄 팁

키는 화면의 🔑 메뉴에서 입력하며, 사용하는 브라우저에만 보관됩니다. 키가 없어도 기본 학습 기능은 모두 쓸 수 있습니다.

## 사용 방법

별도 설치나 빌드가 필요 없습니다.

- `latin365.html`과 `img/` 폴더를 같은 위치에 두고 브라우저로 `latin365.html`을 엽니다.
- 웹에 배포할 때도 두 가지를 함께 올리면 됩니다.
- 데스크톱과 모바일 화면을 모두 지원합니다.
